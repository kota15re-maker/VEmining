# 制作ハンドブック — 「読み込み中のあなた」の技法一式

このフォルダ（`loading_you/`）を別のプロジェクトへ移して、同じ質の映像を作り続けるための手引きです。15秒の初稿から45秒版までの制作で決めたこと、試して効いたこと、失敗して直したことを全部まとめています。

- 作品の現状と区間ごとの内容は `README.md`
- 素材画像の出典とライセンスは `assets/CREDITS.md` と `assets/manifest.json`
- Claude Code に同じ方針で作業させるためのスキルは `skill/SKILL.md`（使い方は最後の章）

---

## 0. 必ず守ること（要約）

1. **既存の作家名・作品名を出さない。** 既存作品の再現ではなく、技法として組み直す。
2. **「かわいい・静か・整った画面」と「壊れた・不穏・異質な画面」を行き来させる。** グリッチを盛るだけにしない。静の画面は、戻るたびに何かが1つ増えているか、少し間違っている。
3. **文字は2種類を必ず両方使う。** 「読みづらいが読める文章」と「完全に読めない文字」（第2章）。
4. **異素材は馴染ませない。** 置換・侵食・切断・断片化・異物の挿入で関係づける（第6章）。
5. **同じ技法の繰り返しに頼らない。** 破壊の回ごとに手法の系統を変える（第5章）。
6. **素材画像は再利用条件が明確なものだけ。** 出典とライセンスを1枚ずつ記録する（第7章）。
7. **画質を守る。** 破壊は最近傍・ハードエッジの変形で作り、画素を溶かす処理は最小限にする（第9章）。
8. **光の点滅を抑える。** 画面全体の大きな明暗反転は、どの1秒間でも4回（明滅2回）以下にする（第10章）。
9. **書き出すたびに数値で確かめる。** `tools/qa_check.py` を回す（第11章）。

## 1. コンセプト

- タイトル「読み込み中のあなた」。パステルのロード画面に座るマスコットに、別のデータ（別個体B、写真、植物、人の体の断片）が上書きされていく。
- ルールは「壊れるたびに画面内の何かが1つ増える」。ラストは最初と同じ画面に戻るが、増えたものが残っている（窓が2枚、目が2pxずれ、2行目の5文字目が化けたまま、奥の窓に小さな花、隅から伸びる蔓）。
- 進行バーは98%で止まり、最後に99%まで1%だけ進む。完了はしない。
- 古いデジタル質感（低解像度、CRT、スキャン、網点、ビデオテープ）を、現代的な編集リズム（ジャンプカット、スナップバック、スタッター）で組み直す。
- 最初の0.1秒（3フレーム）のフックで視線を掴み、ループで最初に戻る。

### 登場するもの

| 要素 | 内容 |
| --- | --- |
| マスコットA | 淡ピンクの丸いぬいぐるみ風。耳、黒目、ほっぺ、ω口。`mascot(scale, edx, edy, variant=0, blink)` |
| マスコットB | Aの下に潜む別個体。淡青、一つ目（赤い瞳孔）、ほっぺに×印、一文字口。`variant=1` |
| OS風ウィンドウ | タイトルバー、疑似文字の1行目、読める2行目、進行バー。`make_window(progress, l1, l2, style)` |
| エラーダイアログ | 赤いタイトルバー、黄緑のアイコン。1〜2フレームだけ。`error_box()` |
| 紙背景 | クリーム色、粒、繊維、ムラ、周辺減光。6枚を12fpsで巡回 |
| フッター | 疑似文字の1行と点滅するカーソル |

## 2. 文字の扱い（2種類を必ず両方使う）

画面の文字は、次の2種類を意識して使い分ける。どちらか片方だけにしない。

### A. 読みづらいが読める文章

一瞬しか映らない、小さい、欠けている、ずれている——でも**一時停止すれば「こう書いてある」と分かる**文章。見返した人だけが気づく層を作る。

- **中身は本物の日本語の文。** 意味は通るが、説明しきらない。作品の主題（読み込み、待つこと、上書き、入れ替わり、増えるもの）に触れる。例：「しばらくおまちください」「まだ読み込んでいます」「あなたの代わりが先に着きました」「ここは前にも見た画面です」「ひとつ増えています」。既存の作品名・作家名・実在の人物名は入れない。
- **読みづらくする方法**（どれか1〜2つ。全部かけると読めなくなる）
  - 表示を1〜3フレームだけにする（エラーダイアログの本文、窓の差し替わる瞬間、ジャンプカットの間など）
  - 文字を小さくする（12〜14px）、コントラストを下げる（フッターと同じ `FOOTC` など）
  - 1行の中の一部の文字（2割まで）を疑似文字に差し替える、上下や左右に1〜2pxずらす、走査線や帯で一部を欠けさせる
  - 画面の隅、窓のタイトルバー、網点の中、団地の窓の中など、目の行きにくい場所に置く
- **守ること**
  - 読める部分が文として成立していること。欠けさせるのは2割まで。
  - **書き出したあと、その文が出るフレームを静止画で書き出して、実際に読めるか確かめる**（`python3 render_45s.py preview <秒>` で出る `preview.png` を見る）。
  - 文ごとに、いつ・どこに・何フレーム出すかを表にして残す（どの区間に何が書いてあるかを把握できるように）。

### B. 完全に読めない文字

どう見ても読めない、でも文字らしく見える形。UIのノイズ、質感、リズムとして使う。

- **合成かな**（`chimera()`）：実在のかな2文字を左右・上下で切って繋ぐ、鏡像にして重ねる。
- **ドット記号**（`blockglyph()`）：左右対称のドットの塊。
- **図形記号**：▓░◆◇□■※¤§¶∴∵⌘◐◑△▽ など。
- 偶然に実在の語にならないよう、読める文字（`READ_ID`）とは別の番号帯に置いている（`GL[:NPSEUDO]` が疑似文字、その後ろが読める文字）。

### 今の45秒版での使い分けと、足りないところ

| 種類 | 今あるもの |
| --- | --- |
| A（読みづらいが読める） | ウィンドウ2行目「しばらくおまちください」。途中から1文字ずつ化け、帰還では5文字目だけ化けたまま |
| B（読めない） | タイトル、1行目、フッター、エラーダイアログ、文字の雨、文字化の画面、眉になる文字、団地の窓の文字 |

**Aが1種類しかないので、次の制作ではAを増やす。** 例えば、エラーダイアログの本文を2フレームだけ読める文にする、ジャンプカットの2コマに小さな文を入れる、網点の版ずれの中に1行だけ読める文を刷る、団地の窓の1つに読める張り紙を入れる、帰還の画面のフッターに一瞬だけ読める文が出る、など。実装は、読める文を `READ` と同じ方法で `GL` に足し（`cmask(c, fK)`）、`stamp()` で置く。欠けさせるときは `CORR_ORDER` と同じ考え方で、どの文字を何番目に化けさせるかを固定する。

| --- | --- |

| フレームレート | 30fps。マスコットの脈動、紙のちらつき、文字の変化などは12fps相当で保持（`int(t*12)`）、エフェクトは30fps |
| 仕上げ（`finish()`） | 3行に1行を16%暗くする走査線、R/Bを1pxずつ逆にずらす色収差、周辺減光 |

| 役割 | 色 |
| --- | --- |

## 4. 構成の作り方

### 静と暴の往復

- 破壊の回ごとに、強く、長くしていく。間に挟む「静」は短く（0.5〜1秒）、戻るたびに**何かが1つ増えているか、少し間違っている**。静を「本物 → アイコンが1つ多い → マスコットが別物 → 体の中が風景 …」と少しずつ偽物にすると、見る側が間違い探しをするので、静の区間でも目が離れない。
- 尺を伸ばすときは、同じ構成を引き延ばさない。破壊の回数を増やし、回ごとに違う手法の系統を割り当てる。
- 破壊区間は全体の5割強（15秒版53%、45秒版も同程度）。

### 45秒版の区間表（`SEGS`）

| 秒 | 区間 | 手法の系統 |
| --- | --- | --- |
| 0.0–0.1 | フック | 反転してマゼンタとシアンに分離、巨大な疑似文字 |
| 0.1–2.4 | 静 I | 本物。進行バーが98%で止まる。2.1秒から予兆 |
| 2.4–3.6 | 破壊1「裂け」 | ずらす |
| 3.6–4.6 | 静 II | 写真アイコンが残り、蔓が1本出る |
| 4.6–7.0 | 破壊2「操作」 | UIで壊す |
| 7.0–7.8 | 静 III | Bが座る。一つ目が本物の眼球 |
| 7.8–11.8 | 破壊3「暴走」 | 15秒版の暴走 |
| 11.8–12.3 | 静 IV | 残骸ごと止まる |
| 12.3–15.3 | 破壊4「紙」 | 紙と印刷 |
| 15.3–16.3 | 静 V | 左半分A、右半分B、継ぎ目に水面 |
| 16.3–22.8 | 破壊5「侵食」 | 植物・水・顔 |
| 22.8–23.6 | 静 VI | 花と蔓が残る |
| 23.6–28.1 | 破壊6「コラージュ」 | 帯・図形・窓 |
| 28.1–28.8 | 静 VII | 体の中が風景 |
| 28.8–34.8 | 破壊7「全壊」 | 新しい型を1つずつ、最後はタイル |
| 34.8–35.3 | 崩落 | 解像度が落ちきって1点に |
| 35.3–37.3 | 無音の間 | 完全な無音。花びらが1枚落ちる |

## 5. 破壊の技法カタログ

回ごとに系統を変える。同じ系統を2回使わない。**画素を溶かさない（最近傍・ハードエッジ）**ものを基本にする。

### ずらす（破壊1「裂け」）
- `slices(A, B, ...)`：横の帯を左右にずらし、ずれた隙間から下の層（B、風景）が見える。最初は目の高さだけ、後半は画面全体。
- 写真ブロックが右下に刺さり、0.5秒ごとに入れ替わる。黄緑の帯1フレーム、エラー2フレーム。
- `bg_only()`：マスコット以外だけRGBをずらす。

### UIで壊す（破壊2「操作」）
- カーソルが目を範囲選択（点線の選択枠 `marching_ants()`）→ 切り取り（顔に四角い穴）→ 画面中に貼り散らかす。3回目から、貼る中身が写真の目に変わる。
- 窓が0.06秒ごとに湧き、残像の尾を引いて漂う。窓の中身が写真に置き換わる（`WIN_CONTENT`）。
- エラーダイアログが連鎖して階段になる。
- 目のない本体が飛び出して跳ね回り、軌跡が消えずに残る（`bounce_path()`）。目の穴の奥は空。

### 15秒版の暴走（破壊3）
- 拡大縮小の往復、写真の全面・部分表示、ブロック破損、行の反転、赤紫のデュオトーン、巨大な疑似文字、エラー。乱数は12fpsで保持。
- **静かなクローズアップへのジャンプカット**（2コマ）：目、眼球、窓の角、唇になったフッター。全面写真の最中には挟まない。

### 紙と印刷（破壊4「紙」）
- `halftone()`：CMYの網点に分解し、版を少しずつずらす。
- `scan_slip()`：その印刷物をスキャナーで読む。読み取りバーが下り、紙が引っかかった行が伸び、帯ごとに横へ滑る。
- `paper_rip()`：紙が斜めに裂け、上半分が回転しながら剥がれ落ち、下から別の層（病棟とBの写真）が出る。
- 前の段階の結果を次の段階の入力にする（印刷→スキャン→破れ）。物理的な物語になる。

### 侵食（破壊5「侵食」）
- 蔓（`draw_vines()`）、カビの染み（`mold()`）、頭や窓に咲く花、版画の線の刷り重ね（`ink_overlay()`）。
- 水位が上がる（`flood()`）。水面の下は、上の景色の揺れる映り込み＋沈んだものの歪んだ姿＋水面の写真。
- 風景の上に顔の断片（写真の目、文字の眉、マスコットの鼻、写真の唇）が集まる。瞬きし、音のないまま口が動く。唇から円が広がって水面へ切り替わる。

### コラージュ（破壊6）
- 縦の帯（`collage_strips()`）：帯ごとに違う文脈の画像。帯は別々の速さで流れ、0.25秒ごとに一部が差し替わる。
- 図形の穴（`collage_shapes()`）：アーチ、円、三角、傾いた四角から、それぞれ違う世界が覗く。縁に1pxの線。大きな疑似文字の断片。
- 団地の窓（`collage_facade()`）：窓ごとに目、唇、花、進行バー、文字、B、解剖模型などが入り、ときどき入れ替わる。最後に真ん中の窓（元の画面が小さく入っている）へズームして、次の静へ繋ぐ。拡大中の窓の中身は、縮小した画ではなく元解像度の画を窓の大きさに合わせて貼る（ぼけない）。

### 全壊（破壊7）：新しい型を1つずつ
| 型 | 関数 | 見え方 |
| --- | --- | --- |
| パズル | `puzzle()` | 6×10のタイルがスライドパズルのように入れ替わる。タイルの一部は別の写真から。抜けた所から下の層 |
| ラスター | `raster()` | 行ごとに横へ波打つ。色版ごとに位相がずれ、後半は斜めに流れる |
| 文字化 | `textize()` | 画面を疑似文字のモザイクに拭い替える。ところどころ花や目が混ざる |
| 折り返し | `kaleido()` | 左右がAとB、四方対称、目の壁紙を12fpsで切り替え |
| 入れ子 | `tunnel()` | 画面の中に画面が無限に続く。層ごとに明るさを揃える |
| 巻き戻し | `vhs()` ＋ `fx_breakdown()` | 暴走をビデオテープの早戻しで逆再生（写真は出さない） |
| 溶解 | `melt_fx()` ＋ `pixel_sort()` | 列ごとに垂れ落ちる、ピクセルソートの筋 |
| 色の巡回 | `palette_cycle()` | 4色に減色して回す。紙の色は固定 |

型の長さは0.85秒→0.5秒と短くしていき、最後に短いカットで一巡、最後の0.6秒は画面を3×5のタイルに割って型ごとの画を並べる。

### 崩落と無音
- 崩落：解像度が段階的に落ちていき（`mosaic()`）、最後の1点が次の場面の小さなマスコットになる。
- 無音の間：サンプル値を完全にゼロにする。花びらが1枚だけ、音もなく落ちる。一度だけ瞬く。

## 6. 編集リズム

- **スナップバック**（`is_snap()`）：破壊の途中に1コマ（12fps）だけ静の画面へ戻る。回数を少しずつ増やす。写真が出る型の途中では戻らない（明滅になる）。
- **ジャンプカット**（`is_closeup()`）：静かなクローズアップを2コマだけ。1/3秒の区切りの頭に置く。
- **引っかかり**：0.1秒単位で映像と音を同時に止める（音は頭の20msを繰り返す）。
- **予兆**：破壊の直前に1pxの振動と滲み、目が左右を見る、ハムが歪む。
- **余震**：帰還の途中に3フレームだけ、別の手法（ビデオテープの乱れ）で壊れる。
- **フックとループ**：冒頭と末尾に同じ3フレーム。
- **コマ数の混在**：動きは12fps、エフェクトは30fps。目だけ1コマ遅れる（`edx` に前のコマとの差を足す）。

## 7. モチーフと関係づけ方

花、植物、人の目・唇・手・身体、風景、室内の空間、建物、水面、写真断片、図形、UI、文字断片を併置・重層化する。**自然に馴染ませない。** 素材は小さく縮めてから最近傍で拡大し、ドットのまま差し込む。

| 方法 | 具体例 |
| --- | --- |
| 置換 | 貼るたびに目が人間の目に変わる。Bの一つ目が本物の眼球。フッターの文字が唇。マスコットの体の中が風景。窓の中身が写真 |
| 侵食 | 写真アイコンから出た蔓が、静に戻るたびに少しずつ伸び、侵食で画面を覆い、帰還後も隅で伸び続ける。カビ、水位の上昇、解剖図の線が下から這い上がる |
| 切断 | 裂け目の奥が風景。A/Bの継ぎ目を水面が縦に切る。縦の帯。図形の穴 |
| 断片化 | 顔の断片が集まって顔のようなものになる。団地の窓ごとに別の断片。パズルのタイルが別の写真から来る |
| 異物の挿入 | 紙の下に病棟とB。文字化の画面に花や目。入れ子に廊下や風景。無音の間の花びら |

意味がありそうで説明しきれない関係にする。説明的な組み合わせ（目の横に「目」と書くなど）は避ける。

## 8. 素材画像の集め方・選び方・扱い方

### 集める（`tools/fetch_assets.py`）

| サイト | 使う条件 | API |
| --- | --- | --- |
| Wellcome Collection | ライセンスが Public Domain Mark（`pdm`）か CC0（`cc-0`） | `https://api.wellcomecollection.org/catalogue/v2/images?query=…&locations.license=pdm,cc-0&include=source.contributors,source.genres,source.subjects`。作者と年代は `/works/{id}?include=production,contributors` から。画像はIIIFの `…/full/!1600,1600/0/default.jpg` |
| Library of Congress | 権利表示 `rights_advisory` が「No known restrictions」で始まるか public domain。「not evaluated」「may be restricted」「permission」などを含むものは使わない | `https://www.loc.gov/photos/?q=…&fo=json`、各資料は `https://www.loc.gov/item/{id}/?fo=json`（`http://` ではなく `https://`、`Accept: application/json` を付ける） |

- 権利が曖昧なものは使わない。CC BY はクレジット表記が必要なので今回は外した（使う場合は表記を必ず付ける）。
- 同じ資料からは2枚まで。見た目がほぼ同じ画像（平均ハッシュの差が10未満）は1枚だけ。
- サイトへの負荷を避けるため、リクエストの間に0.5〜1秒待つ。
- 1枚ごとに記録するもの：元ページURL、画像URL、ライセンス（id、名前、URL）、権利表示の全文、題名、作者、年代、検索語、取得日時、SHA-256（`assets/manifest.json`）。一覧は `assets/CREDITS.md`。
- 検索語はカテゴリごとに両サイトへ振り分ける（`QUERIES`）。目、顔、口、手、身体、花、植物、風景、水、建物、室内、器具、図版、印刷物。

### 選ぶ

- 完成された1枚の作品より、**切り抜きやすい**図版・古写真・印刷物。
- 普通のストック写真より、**癖や質感のある**もの：眼科図版、水彩の医学画、表情の記録写真、ダゲレオタイプ、ティンタイプ、解剖図、透明標本、植物画、本草書、オートクローム、ステレオ写真、団地や病棟の写真、光学図版、活字見本、薬の広告。
- 時代・構図・質感を混ぜる。同じような画像ばかりにしない。
- 手順：`python3 tools/contact_sheet.py` でカテゴリごとの一覧を作って見比べる → 使うものを決める。検索語と合わない画像（「eye close-up」で羊が出る、など）は外す。

### 切り抜く（`assets/crops.json`）

```json
{"file": "wellcome/ycbgbwtb.jpg", "kind": "eye", "rbox": [0.04, 0.37, 0.21, 0.47], "mask": "ellipse"}
```

- `rbox` は画像の幅・高さに対する比率（0〜1）。`box` ならピクセル。
- **目や口の範囲は、目分量ではなく拡大して測る。** 顔の周りだけを切り出し、2%ごとの目盛りを重ねた画像を作って読む。一覧の縮小画像から読むと外れる（実際に、肌や眉だけが切れていたことがある）。切り抜いた結果を並べた確認用の画像を作って、全部目で確かめる。
- `kind`：eye（片目）、eyes（両目）、eyeball（眼球）、mouth、face、hand、body、flower、plant、landscape、water、sphere（映り込む球）、building、interior、instrument、diagram、print。
- `mask`：
  - `rect`：四角のまま
  - `ellipse`：楕円に切る（目、口、眼球、球）
  - `ink`：紙を抜いて線だけ残す。紙の明るさ（中央値）より48以上暗い所だけを線とみなす（固定の百分位で切ると紙の粒まで拾う）。細い線は小さく縮めると消えるので、刷り重ねるときは大きめ（160×230以上）で使う
  - `subject`：背景色（四辺の中央値）との差で抜く（`thr` で調整）。白い紙の植物画、黒背景の模型に効く

### 扱う

- 使う大きさ（例：目64×32、眼球40×40、全面90×160）に縮めてから、最近傍で拡大する。ほかの画面と同じドットになり、写真だけが浮かない。
- 写真の目の瞬きは、まぶたの色（上端の肌の中央値）で上から塗り下ろす（`_lid()`）。
- 水面の写真は、行・列ごとに少しずらして12fpsで揺らす。
- 暗い写真が画面全体を覆う場面（入れ子など）は、層ごとに平均の明るさを揃える。
- 素材が無いカテゴリは、描いたモチーフで動くようにしておく（`has(kind)` で分岐）。
- 使わなかった候補は `python3 tools/fetch_assets.py --prune` で画像を消し、記録だけ `assets/candidates.json` に残す。

## 9. 音響

- **2つの層**に分ける。静の層（60/120Hzのハム、ヒス、進行クリック）と、破壊の層（ビットクラッシュ、矩形波、掃引）。破壊の層は、映像と同じ判定（`destroying()`）でマスクする。スナップバック、B単独のコマ、ジャンプカットで、音も同時に切れる。
- 区間ごとに音の系統を変える：裂け（衝撃音、クラックル、エラー2音）、操作（クリック、切り取りの擦過音、貼り付け、窓、エラーの連打、跳ねる音）、暴走（0.1秒グリッドのスタッター、48Hz）、紙（網点の干渉音、スキャナーのモーター、紙の裂ける音）、侵食（伸びる植物の弾ける音と軋み、花が開く音、水と泡、息と低い和音）、コラージュ（局が変わるラジオ、図形の風切り音、団地の環境音）、全壊（型ごとに違う音。巻き戻しは暴走の音の逆再生）、崩落（ビット深度とサンプル数が落ちて消える）。
- 静の場面の一部はハムの周波数を下げて濁らせる（入れ替わり55Hz、半分52Hz）。
- 無音の間はサンプル値を完全にゼロ。復帰は30msでフェードイン。
- ラウドネスは -14 LUFS に合わせ、山は簡単なリミッター（5msごとのピークから利得を決める）で抑える。AACで山が少し上がるので、天井は 0.63 にしている（トゥルーピーク -1 dBFS 前後）。

## 10. 画質と光の点滅

### 画質を守る
- 破壊は、ずらす・並べ替える・折り返す・置き換える、で作る（最近傍・ハードエッジ）。1080pに拡大してもドットのまま残る。
- JPEG劣化（`crush_region()`）は帯状の一部だけ、モザイク（`mosaic()`）は崩落の数フレームだけ。使ったフレームは `LOSSY` に記録され、45秒版では30フレーム（画面14.5枚分）。
- 乱数や細かい模様は12fpsで保持する。毎コマ全体が入れ替わると圧縮で潰れる。網点の区間では紙の粒のちらつきも止める。
- 書き出しは H.264、CRF 18、preset slow、tune animation、yuv420p。CRF 20・medium より破壊区間で1.1〜1.5dB良い。
- yuv420 は色を間引くので、細かい色の点（網点など）はにじむ。これは形式の限界で、投稿先の再圧縮でも同じ。色で見せたい細部は大きめにする。
- GitHub の1ファイル上限は100MB。45秒で約68MB。

### 光の点滅を抑える
- 画面全体の平均輝度が40段階以上変わる回数を、どの1秒間でも4回（明滅2回）以下にする。
- 全面の写真は1/3秒単位でしか切り替えない。
- デュオトーンは周りと明るさを揃えた色にする。
- 全面写真の最中には、明るいジャンプカットやスナップバックを挟まない（`photo_full()` と同じ順番で乱数を引いて判定する）。
- 暗い写真が入る入れ子などは、層の明るさを揃える。
- 色の巡回では紙の色を固定する。
- 実際に引っかかった例：暴走のジャンプカットが暗い全面写真の間に入った、入れ子で暗い病棟の写真が明るい画面と交互になった。どちらも上の対策で直した。

## 11. 作業手順とチェックリスト

### 新しい動画を作るとき
1. コンセプトと「増えていくもの」を決める。
2. 区間表（`SEGS`）を作る。破壊の回ごとに手法の系統を割り当てる（第5章から選ぶか、新しい系統を足す）。
3. 読める文章（A）を、いつ・どこに・何フレーム出すか決める（第2章）。
4. 素材画像を集める（`tools/fetch_assets.py`、検索語は内容に合わせて `QUERIES` を書き換える）→ 一覧で選ぶ → `crops.json` に切り抜きを書く → 確認用の画像で全部見る。
5. `python3 render_45s.py preview <秒> …` で主要なコマを確かめながら作る。
6. `python3 render_45s.py video out.mp4` で書き出す（45秒で約4分）。
7. `python3 tools/qa_check.py render_45s.py out.mp4` で数値を確かめる。
8. `python3 tools/fetch_assets.py --prune` で使わない候補を片付け、`CREDITS.md` を作り直す。

### 書き出したら確かめること
- [ ] 大きな明暗の反転が、どの1秒間でも4回以下
- [ ] JPEG劣化・モザイクのフレームが最小限（帯状か崩落だけ）
- [ ] 統合ラウドネス -14 LUFS 前後、トゥルーピーク -1 dBFS 前後
- [ ] 無音の間が完全な無音（-90dB以下）
- [ ] 読める文章（A）の出るフレームを静止画で見て、実際に読める
- [ ] 読めない文字（B）が偶然に実在の語になっていない
- [ ] 静の画面が、戻るたびに何か1つ増えているか、少し間違っている
- [ ] 同じ系統の破壊を2回使っていない
- [ ] 使った素材画像がすべて `manifest.json` と `CREDITS.md` に載っている
- [ ] ループの繋ぎ目（最後の3フレーム→最初）が自然
- [ ] 動画ファイルが100MB未満

## 12. つまずいた点と対処

| 起きたこと | 対処 |
| --- | --- |
| クラウド環境から素材サイトに繋がらない（403） | 環境のネットワーク設定で `api.wellcomecollection.org`、`iiif.wellcomecollection.org`、`www.loc.gov`、`tile.loc.gov` を許可する。設定を変えたら新しいセッションで反映されることがある |
| LoC が Cloudflare の確認ページを返す | 一般的なブラウザ風の User-Agent（`Mozilla/5.0` だけ）だと弾かれる。用途を書いた User-Agent（`loading-you-collage/1.0 (…)`）と `Accept: application/json` で通常どおり応答する |
| Wellcome の `include=source.production` が400 | images では使えない。作者と年代は works から取る |
| LoC の `rights_advisory` が文字列で返る | リストとして扱うと1文字ずつに分かれて判定が壊れる。文字列として判定する。「restriction」を除外語にすると「No known restrictions」まで弾くので、除外語は「not evaluated」「may be restricted」「permission」など具体的にする |
| LoC の画像が画像として読めないことがある | 読めないものは飛ばして続ける |
| 切り抜きが肌や眉だけになる | 一覧の縮小画像で位置を読まない。顔の周りを拡大して目盛りを重ねて測る |
| 線画の `ink` マスクで紙の粒まで残る | 紙の明るさ（中央値）からの差で切る。細い線は大きめで使う |
| 暴走のジャンプカットが明滅になる | 全面写真の最中には挟まない |
| 入れ子で明滅が毎秒5回に増える | 層ごとの明るさを揃え、ズームの周期を遅くする |
| 網点の区間がRGBで22〜24dBまで下がる | 原因は yuv420 の色の間引き（無圧縮でも23dB）。輝度では35dB前後で問題ない |
| 音量が -18 LUFS 前後に留まる | ピークで正規化すると山の高いクリック音に引っ張られる。-14 LUFS に合わせてからリミッターをかける |

## 13. ファイル構成と移し方

```
loading_you/
  render.py              15秒版の原本（制作者のもの、無変更）
  render_45s.py          45秒版の生成スクリプト（素材は render.py と同じ関数、構成と技法を追加）
  loading_you_45s_1080x1920.mp4
  contact_sheet.png
  README.md              作品の内容、区間ごとの説明
  HANDBOOK.md            この手引き
  skill/SKILL.md         Claude Code 用のスキル
  assets/                素材画像、manifest.json、CREDITS.md、crops.json、candidates.json
  tools/fetch_assets.py  素材を集める
  tools/contact_sheet.py 素材の一覧を作る
  tools/qa_check.py      書き出した動画の品質チェック
```

別のプロジェクトへ移すときは、このフォルダを丸ごとコピーする。Claude Code に同じ方針で作業させるには、`skill/` を移し先の `.claude/skills/loading-you-style/` にコピーする（`SKILL.md` が入った状態）。

必要なもの：Python 3、numpy、Pillow、ffmpeg（libx264とaac入り）、Noto Sans CJK と DejaVu Sans。フォントや ffmpeg の場所は環境変数（`FONT_KANA`、`FONT_SYM`、`FFMPEG`）で変えられる。
