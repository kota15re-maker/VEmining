# 読み込み中のあなた — 30秒版

15秒の初稿を30秒に延ばし、破壊を大胆に繰り返す構成に組み直した版です。

- 成果物: `loading_you_30s_1080x1920.mp4`（1080×1920、30fps、30.0秒、全900フレーム、音声付き）
- 生成スクリプト: `render.py`。紙、疑似文字、ウィンドウ、マスコット、写真断片、エフェクト、フックは15秒版の生成コードをそのまま引き継ぎ、タイムラインと破壊の型を30秒用に作ったもの。映像も音もすべて手続き的に生成
- 確認用: `contact_sheet.png`（主要な時刻のコマを並べたもの）

## 考え方

**破壊は5回です。回を追うごとに強く、長くなり、間に挟む「静」は短く、少しずつ間違っていきます。** 静に戻るたびに画面の何かが1つ増える、というコンセプトのルールがそのまま構成になっています。

| 破壊 | 型 | 直後の「静」で増えている／おかしいもの |
| --- | --- | --- |
| 1「裂け」（2.4–3.6秒） | 顔が裂けてBが出る。裂け目が全画面に走り、写真が突き刺さる。途中で一瞬だけ静に戻る | 写真（手）が1枚、アイコンとして残る。2行目の3文字が化けたまま |
| 2「増殖」（4.4–6.8秒） | ウィンドウが20枚湧き、エラーが連鎖して赤い斜めの帯になる。拍に合わせてズームが突っ込む | 座っているのがBに入れ替わっている。窓は2枚 |
| 3「暴走」（7.6–11.6秒） | 拡大縮小3往復、写真、文字の雨、帯の反転、モザイク、JPEG劣化 | 止まるが、窓10枚も写真も化けた文字も残ったまま。目が4pxずれる |
| 4「溶解」（12.0–15.0秒） | 画面が列ごとに溶け落ちる。ピクセルソートの筋、反転したBの縞、後半は縦ロール。映像と音が0.1秒単位で引っかかる | 左半分がA、右半分がB |
| 5「全壊」（16.0–21.5秒） | 1〜4の型が0.7秒→0.15秒と加速しながら入れ替わる。静へのフラッシュバックが増えていき、最後は全部重なる | 崩落して無音へ。帰還すると窓2枚、目2pxのずれ、5文字目が化けたまま |

帰還の途中（27.3秒）にも3フレームだけ余震が来ます。

15秒版との比較（1080pを縮小して隣り合うコマの差を測ったもの）：

| | 15秒版 | 30秒版 |
| --- | --- | --- |
| 大きく動くコマの割合 | 21% | 43% |
| コマ間の平均変化量 | 11.2 | 11.6 |
| 破壊区間の割合 | 約53% | 約54% |

## タイムライン

| 区間 | 名前 | 画面 | 音 |
| --- | --- | --- | --- |
| 0.0–0.1s | フック | 反転してマゼンタとシアンに分離。巨大な疑似文字（3フレーム） | ビットクラッシュの轟音 |
| 0.1–2.4s | 静 I | 進行バーが0.5–2.2秒で12%→98%。1.9秒に瞬き。2.1秒から予兆（1pxの振動と滲み、目が左右を見る） | ハム、進行クリック。予兆で歪む |
| 2.4–3.6s | 破壊1「裂け」 | 上表のとおり。2.6秒に黄緑の帯、2.9秒と3.25秒にエラー。12fpsの1コマ単位で、ときどき静の画面に戻る | 落下する衝撃音、裂けるクラックル、エラー2音、スタッター |
| 3.6–4.4s | 静 II「偽の復旧」 | 手の写真がアイコンとして残る | ハムだけ |
| 4.4–6.8s | 破壊2「増殖」 | 窓が0.11秒ごとに湧き、残像の尾を引いて漂う。5.2秒からエラーの連鎖。背景だけRGBずれ、シアンとマゼンタの線 | 窓が湧くたびのブリップ、エラー音の連打 |
| 6.8–7.6s | 静 III「入れ替わり」 | Bが何食わぬ顔で座る。7.2秒にBが瞬く | ハムが55Hzに下がる |
| 7.6–11.6s | 破壊3「暴走」 | 9.6秒に3フレームだけB単独の静かな画面。8.8秒と10.6秒に赤紫のデュオトーン | スタッター、拡大縮小に同期した48Hz。B単独のコマは無音 |
| 11.6–12.0s | 静 IV「凍結」 | 残骸ごと止まる | ハムだけ |
| 12.0–15.0s | 破壊4「溶解」 | 上表のとおり。最後はモザイクで切れる | 220Hz→30Hzへ落ちていくドローン。映像と同じ瞬間に音も引っかかる |
| 15.0–16.0s | 静 V「半分」 | 左半分がA、右半分がB。15.5秒に瞬き | ハムが52Hzに下がる |
| 16.0–21.5s | 破壊5「全壊」 | 上表のとおり。18.5秒に3フレームだけB単独。20.8秒から全部重ねた最大値 | 後半は0.05秒刻みのスタッター、8Hzで刻む40Hz |
| 21.5–22.0s | 崩落 | 縦に潰れて1本の線になり、点になる | テープが止まるような下降音 |
| 22.0–23.8s | 無音の間 | 白い紙に小さなマスコット1体。23.0秒に一度だけ瞬く | 完全な無音（サンプル値ゼロ） |
| 23.8–29.9s | 帰還 | 冒頭と同じ画面。ただし窓2枚、目が2px右、5文字目が化けたまま。手前の窓の進行バーが24.4–26.6秒に溜まり直し、28.6秒に99%。27.3秒に余震。29.4秒から予兆、29.6秒にBが1フレーム覗く | ハムが30msで復帰。進行クリック。余震のノイズ |
| 29.9–30.0s | ループ繋ぎ | フックの3フレームを再掲 | 冒頭と同じ轟音 |

どの破壊でも、静に戻る瞬間は音も同時に切れます（破壊の音は別の層で作り、映像と同じ判定でマスクしています）。

## 光の点滅への配慮

破壊を大胆にしても、画面全体が明暗に大きく反転する回数は抑えています。

- 全面の写真は1/3秒単位でしか切り替えない。細い帯状の写真はコマ単位で差し込む
- デュオトーンは周りと明るさを揃えた赤紫（#B02480→#FFB096）
- 全壊の途中で静に戻るコマは、写真が出る型の途中では起きない

画面全体の平均輝度が大きく（40段階以上）変わる回数は、どの1秒間でも最大4回（明滅2回）です。光過敏への配慮の目安である毎秒3回の明滅は下回っています。15秒版の暴走区間の強さ（0.1秒ごとに全面写真）は、この制約のため再現していません。

## 再現手順

Python 3、numpy、Pillow、ffmpeg（libx264とaac入り）、Noto Sans CJKとDejaVu Sansが必要です。

    pip install numpy pillow
    python3 render.py preview 0 1.0 3.0 5.5 9.0 13.5 18.0 26.0   # 指定秒のコンタクトシート
    python3 render.py video out.mp4                               # 音声付きで書き出し（1〜2分）

パスは環境変数で上書きできます（`FONT_KANA`、`FONT_SYM`、`FFMPEG`、`OUT_DIR`、`CRF`）。乱数はフレーム番号で固定しているので、何度回しても同じ結果になります。

構成は`render.py`冒頭の`SEGS`（区間の表）と、`BLINKS`、`ERRORS`、`QUIET`、`AFTERSHOCK`、`DUOTONE`にまとめてあり、映像と音の両方がここを参照します。破壊の型は`fx_tear()`、`fx_swarm()`、`fx_rampage()`、`fx_melt()`で、全壊（`sc_climax()`）は`CLIMAX`の予定表に従ってこれらを使い回します。静へのフラッシュバックは`is_snap()`、引っかかりは`is_stutter()`です。

## 写真の差し替え

`photos/`フォルダに画像（jpg、png、webp）を置くと、ファイル名順に写真断片として使われます。低解像度化は自動です。置かない場合は、床タイル、窓、手、カーテン、空、砂嵐の手続き生成の代用品になります。偽の復旧でアイコンとして残るのは`ANOM_TILES`の最後の番号の写真です。
