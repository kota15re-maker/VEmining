# 読み込み中のあなた — 30秒版

15秒の初稿を30秒に延ばし、演出を組み直した版です。

- 成果物: `loading_you_30s_1080x1920.mp4`（1080×1920、30fps、30.0秒、全900フレーム、音声付き）
- 生成スクリプト: `render.py`（初稿の引継書をもとに作り直したもの。映像も音もすべて手続き的に生成）
- 確認用: `contact_sheet.png`（主要な時刻のコマを並べたもの）

## 30秒での考え方

15秒版は「静 → 暴 → 無音 → 帰還」を1周する構成でした。30秒で同じ構成を引き延ばすと、各区間が間延びします。そこで**壊れて戻る周期を3回にして、戻るたびに画面の何かが1つ増える**ようにしました。コンセプトのルールがそのまま構成になります。

| 周期 | 壊れ方 | 戻ったときに増えているもの |
| --- | --- | --- |
| 1回目（4–7秒） | 揺れ、写真の侵入、エラー | 写真が1枚、デスクトップアイコンのように残る |
| 2回目（9.5–14秒） | 顔が裂けてBが覗く、ウィンドウ増殖 | ウィンドウが2枚になり、座っているのがBに入れ替わっている |
| 3回目（15.5–21秒） | 暴走、崩落 | 最初と同じ画面に戻るが、ウィンドウ2枚、目が2pxずれ、5文字目が化けたまま |

「静」の区間は毎回少しずつ偽物になります。1回目の静は本物、2回目はアイコンが1つ多い、3回目はマスコットごと別物です。見る側に間違い探しをさせることで、長い静の区間でも視線が離れにくくなります。

## 15秒版からの変更点

- **周期を3回に**: 静の区間を「本物 → アイコンが1つ多い → マスコットが別物 → ほぼ本物」と4回置き、壊れるたびに増えるルールを見える形にしました
- **新しい場面「入れ替わり」**（14.0–15.5s）: 15秒版では暴走の途中に3フレームだけあったB単独の画面を、1.5秒の静かな場面として独立させました。かわいくて整っているのに間違っている、という状態をはっきり見せる場面です。暴走中の3フレームのB単独カットも残し、呼応させています
- **新しい場面「崩落」**（20.5–21.0s）: 暴走から無音への切り替えを、CRTの電源が落ちる動きで繋ぎました。最後の点が無音区間の小さなマスコットになります
- **写真が残る**: 1回目の異変で侵入した写真のうち最後の1枚（手）が、偽の復旧でアイコンとして残ります。ラストでは消えます
- **5文字目の伏線**: エラーの瞬間に5文字目が一瞬化け、偽の復旧で最初に化けるのも5文字目です。ラストで唯一残る化け文字と繋がります
- **帰還に動きを追加**: 6秒あるので、進行バーの再充填、瞬き、98%→99%の1段、Bの1フレームの覗きで、最後まで目を離させないようにしました
- **無音の間に瞬き**: 2.5秒の完全静止の中で一度だけ瞬きます。音は出しません
- **写真フラッシュを抑制**: 暴走中の写真の切り替えは1/3秒単位（毎秒3回以下）、表示率は約40%です。画面全体の輝度変化を測ると、どの1秒間でも大きな明暗の反転は2.5回以下です（光過敏への配慮の目安である毎秒3回未満）
- **ループ繋ぎを短く**: 末尾のフックは3フレームで、冒頭の6フレームに繋がります

## 書き出し仕様

## 再現手順

Python 3、numpy、Pillow、ffmpeg（libx264とaac入り）、Noto Sans CJKとDejaVu Sansが必要です。

    pip install numpy pillow
    python3 render.py preview 0 1.0 5.3 10.5 14.5 17.0 22.0 26.0   # 指定秒のコンタクトシート
    python3 render.py video out.mp4                                 # 音声付きで書き出し（1〜2分）

パスは環境変数で上書きできます（`FONT_KANA`、`FONT_SYM`、`FFMPEG`、`OUT_DIR`）。乱数はフレーム番号で固定しているので、何度回しても同じ結果になります。

各区間の時刻は`render.py`冒頭の`T_*`定数と`BLINKS`、`ERRORS`、`SPAWNS`、`DUOTONE`にまとめてあり、映像と音の両方がここを参照します。区間ごとの描画は`hook()`、`calm()`、`anomaly()`、`calm2()`、`invasion()`、`swap()`、`rampage()`、`collapse()`、`silence()`、`ret()`です。

## 写真の差し替え

`photos/`フォルダに画像（jpg、png、webp）を置くと、ファイル名順に写真断片として使われます。低解像度化は自動です。置かない場合は、床タイル、窓、手、カーテン、空、砂嵐、水面の手続き生成の代用品になります。偽の復旧でアイコンとして残るのは`ANOM_TILES`の最後の番号の写真です。
