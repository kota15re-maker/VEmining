# 読み込み中のあなた — 45秒版

15秒の初稿を45秒に延ばした版です。破壊を7回繰り返し、回ごとに違う手法を使います。画面には、異なる文脈のモチーフ（花、植物、人の目・唇、風景、廊下、団地、水面、写真断片、図形、UI、文字断片）を併置・重層化しています。

| ファイル | 内容 |
| --- | --- |
| `render.py` | 15秒版の生成スクリプト（制作者の原本。無変更。出力先は `/home/claude/` のまま） |
| `render_45s.py` | 45秒版の生成スクリプト。`render.py` の素材（紙、疑似文字、ウィンドウ、マスコット、写真断片、エフェクト、フック、仕上げ）をそのまま使い、45秒のタイムライン、破壊の型、モチーフを足したもの |
| `loading_you_45s_1080x1920.mp4` | 成果物（1080×1920、30fps、45.0秒、1350フレーム、音声付き） |
| `contact_sheet.png` | 主要な時刻のコマを並べたもの |
| `assets/` | 素材画像（Wellcome Collection、Library of Congress）、`manifest.json`（出典とライセンスの記録）、`CREDITS.md`、`crops.json`（切り抜き範囲）、`candidates.json`（使わなかった候補の記録） |
| `tools/` | 素材を集める `fetch_assets.py`、一覧を作る `contact_sheet.py` |

30秒版（`render_30s.py` と動画）はgitの履歴に残っています。

## モチーフの扱い方

モチーフは画面に馴染ませません。素材画像も描いたモチーフも、小さく縮めてから最近傍で拡大し、ドットのまま差し込んでいます。関係づけ方は5種類です。

| 方法 | どこで | 何が起きるか |
| --- | --- | --- |
| **置換** | 操作、入れ替わり、帰還 | 切り取った目を貼るたびに、3回目から肌ごと切り取った人間の目に変わる。Bの一つ目が血管の走る本物の眼球。帰還中の2フレームだけ、マスコットの目が人間の目になる |
| | 暴走、静VII | フッターの文字が唇になっている（クローズアップ）。マスコットの体の中が風景 |
| | 操作 | 湧いた窓の中身が、文字の代わりに風景、唇、団地、水面、廊下、花畑になる |
| **侵食** | 静II → 静IV → 侵食 → 静VI → 帰還 | 写真アイコンから蔓が1本出て、止まるたびに少し伸び、侵食で画面を覆う（カビの染み、頭から咲く花、窓のタイトルバーの花）。水位が上がり、画面の下半分が揺れる映り込みになる。帰還後も、画面の隅から蔓が伸び続ける |
| **切断** | 裂け、半分、コラージュ | 裂け目の奥が風景。A/Bの継ぎ目を水面が縦に切る。縦の帯ごとに違う文脈。図形の穴から、廊下、風景、団地、眼球、水面、花畑が覗く |
| **断片化** | 侵食（顔）、コラージュ（団地）、全壊 | 風景の上に、人間の目、文字の眉、マスコットの鼻、唇が集まって顔のようなものになる。唇は音のないまま動く。団地の窓ごとに、目、唇、花、進行バー、文字、Bが入っていて、ときどき入れ替わる。パズルのタイルの一部が別の写真から来る |
| **異物の挿入** | 紙、全壊、無音 | 紙が破れた下に廊下の空間があり、奥に小さなBが立っている。文字化した画面のところどころに花や目が混ざる。入れ子の層が廊下と風景を交互に挟む。無音の間に花びらが1枚だけ落ちる |

## 素材画像のコラージュ

描くだけでは難しい目・顔・風景などは、Wellcome Collection と Library of Congress の素材画像を切り抜いて使っています。素材ごとの出典（元ページURL、画像URL）、ライセンス、権利表示、題名、作者、年代は `assets/manifest.json` に、一覧は [`assets/CREDITS.md`](assets/CREDITS.md) にあります。

**選定の基準**

- Wellcome Collection：ライセンスが Public Domain Mark または CC0 のものだけ
- Library of Congress：権利表示（rights advisory）が「No known restrictions on publication」または public domain のものだけ。「未評価」「制限あり」「許諾が必要」などの文言があるもの、表示が無いものは使わない
- 完成された1枚の作品より、切り抜きやすい図版・古写真・印刷物を優先する。モチーフ、時代、質感が偏らないよう、眼科図版、水彩の医学画、表情の記録写真、ダゲレオタイプ、ティンタイプ、解剖図、透明標本、植物画、本草書、オートクローム、ステレオ写真、団地や病棟の写真、光学図版、活字見本、薬の広告などを混ぜる
- 同じ資料からは2枚まで、見た目がほぼ同じ画像は1枚だけ
- 候補として取得したものの使わなかった画像は、画像を消して記録（URL、ライセンス）だけ `assets/candidates.json` に残す

**使い方**（`assets/crops.json` に切り抜き範囲とマスクを記録）

| 素材 | 使う場所 |
| --- | --- |
| 眼科図版の目、水彩の断面の目、表情写真の目 | カーソルが貼り散らかす目、顔の断片、文字化の中の目、団地の窓、帰還中の2フレーム |
| 水彩の断面の青い目 | Bの一つ目（眼球）、図形の穴 |
| 表情写真の口 | 顔の断片の唇（閉じた口と、歯を見せる口） |
| 水彩の風景、ステレオ写真の山 | 裂け目の奥、顔の背景、マスコットの体の中、窓の中身 |
| ルイーズ湖の映り込み、滝 | 水面（12fpsでゆらす）、唇から広がる円 |
| 風景を映す鏡の球（ステレオ写真） | 図形の穴 |
| 団地・オフィスビル・水辺の病院 | 団地の外壁、窓の中身、帯 |
| 病棟、階段 | 紙の破れた下の空間、図形のアーチ、入れ子の層 |
| 解剖図、耳の解剖図、骨格、マンドラゴラ、本草書、植物画 | 侵食で紙の上に刷り重なる線（紙を抜いて線だけ） |
| 植物画の花 | 頭から咲く花、窓の花、水面に浮く花 |
| 透明標本、脳の模型、象牙の解剖模型、顕微鏡、手術器具 | 写真断片、帯、団地の窓、図形の穴 |
| 光学図版、天文図、植物の細胞、活字見本、点字活字、薬の広告、ポスター見本 | 写真断片、帯、団地の窓 |
| 手の身振り一覧、手の三態、手のひらの解剖 | 手の写真アイコン、写真断片 |

素材が無い部分（葉、カビ、廊下の遠近など）は、描いたモチーフのまま使っています。

素材を集め直すときは `python3 tools/fetch_assets.py`、一覧を見るときは `python3 tools/contact_sheet.py`、使わない候補を片付けるときは `python3 tools/fetch_assets.py --prune` です。

## 構成

| 秒 | 区間 | 手法の系統 | 画面 |
| --- | --- | --- | --- |
| 0.0–0.1 | フック | 15秒版のまま | 反転してマゼンタとシアンに分離、巨大な疑似文字 |
| 0.1–2.4 | 静 I | — | 本物。進行バーが98%で止まる |
| 2.4–3.6 | 破壊1「裂け」 | ずらす | 顔が裂けてBが覗く。画面の裂け目の奥は風景。写真ブロックが刺さる |
| 3.6–4.6 | 静 II | — | 手の写真がアイコンとして残り、蔓が1本出る |
| 4.6–7.0 | 破壊2「操作」 | UIで壊す | 目を範囲選択して切り取る。貼り散らかすうちに人間の目になる。窓が湧いて中身が写真になり、エラーが連鎖する。目のない本体が跳ね回る（目の穴の奥は空） |
| 7.0–7.8 | 静 III | — | Bが座っている。一つ目は本物の眼球 |
| 7.8–11.8 | 破壊3「暴走」 | 15秒版の暴走 | 写真に風景、団地、廊下、水面、花畑、顔が混ざる。眼球と唇のクローズアップへジャンプカット |
| 11.8–12.3 | 静 IV | — | 残骸ごと止まる。蔓が伸びている |
| 12.3–15.3 | 破壊4「紙」 | 紙と印刷 | 網点の版ずれ → スキャナーの滑り → 紙が裂けて剥がれ、下から廊下と小さなBが出る |
| 15.3–16.3 | 静 V | — | 左半分がA、右半分がB。継ぎ目を水面が縦に切る |
| 16.3–22.8 | 破壊5「侵食」 | 植物・水・顔 | 蔓とカビが覆い、花が咲く → 水位が上がる → 風景の上に顔の断片が集まり、瞬きし、口が動く → 唇から円が広がって水面へ |
| 22.8–23.6 | 静 VI | — | 窓の周りに蔓と花、頭に花が1輪 |
| 23.6–28.1 | 破壊6「コラージュ」 | 帯・図形・窓 | 縦の帯ごとに違う文脈 → 図形の穴から別の世界 → 団地の窓の中身が入れ替わり、真ん中の窓（元の画面が入っている）へ入っていく |
| 28.1–28.8 | 静 VII | — | 体の中が風景のマスコット |
| 28.8–34.8 | 破壊7「全壊」 | 新しい型が1つずつ | パズル → ラスター → 文字化 → 折り返し → 入れ子 → 巻き戻し → 溶解 → 色の巡回 → 短いカットで一巡 → 型とモチーフのタイル |
| 34.8–35.3 | 崩落 | 解像度 | 解像度が落ちきって1点になる |
| 35.3–37.3 | 無音の間 | — | 小さなマスコット。花びらが1枚落ちる。36.3秒に瞬き |
| 37.3–44.9 | 帰還 | — | 冒頭と同じ画面。ただし窓2枚、目2pxのずれ、5文字目が化けたまま、奥の窓に小さな花、隅から伸びる蔓。41.0秒に2フレームだけ人間の目。42.0秒にテープの乱れ |

音も区間ごとに変えています。侵食では、伸びる植物の弾ける音と軋み、花が開く音、寄せる水と泡、息と低い和音が鳴ります。コラージュでは、帯が替わるたびに局が変わるラジオ、図形の風切り音、団地の環境音と明かりのスイッチ音です。静に戻るコマ、B単独のコマ、ジャンプカットでは、破壊の音が映像と同時に切れます。

## 画質と光の点滅

- **画素を溶かさない：** 破壊とモチーフの差し込みは、最近傍・ハードエッジの変形で作っています。JPEG劣化とモザイクを使ったのは30フレーム（画面14.5枚分）だけです
- **変化を12fpsで保持する：** 暴走の乱数、水面の揺れ、網点区間の紙の粒を12fps単位で保持し、圧縮で潰れにくくしています
- **書き出し設定：** H.264をCRF 18、preset slow、tune animationで書き出しています
- **点滅：** 画面全体の平均輝度が大きく（40段階以上）変わる回数は、どの1秒間でも最大2回です。全面写真の切り替えは1/3秒単位で、全面写真の最中には明るいカットを挟みません

## 書き出し仕様

| 項目 | 値 |
| --- | --- |
| 解像度 | 1080×1920（9:16）。内部は360×640を3倍に最近傍補間で拡大 |
| フレームレート / 尺 | 30fps / 45.0秒（1350フレーム、ループ前提） |
| 映像 | H.264 High、CRF 18、preset slow、tune animation、yuv420p、faststart |
| 音声 | AAC 192kbps、48kHzステレオ。-14 LUFSに合わせ、山はリミッターで抑える |
| 実測 | 約68MB。-14.2 LUFS、トゥルーピーク-0.8 dBFS |
| 仕上げ | 15秒版と同じ（走査線、色収差1px、周辺減光） |

## 再現手順

Python 3、numpy、Pillow、ffmpeg（libx264とaac入り）、Noto Sans CJKとDejaVu Sansが必要です。

    pip install numpy pillow
    python3 render_45s.py preview 0 1.0 3.0 5.5 7.4 9.0 13.0 17.0 19.5 21.5 24.0 26.0 27.8 30.0 33.0 40.0
    python3 render_45s.py video out.mp4        # 音声付きで書き出し（約4分）

パスと画質は環境変数で上書きできます（`FONT_KANA`、`FONT_SYM`、`FFMPEG`、`OUT_DIR`、`CRF`）。乱数は固定しているので、何度回しても同じ結果になります。

構成は `render_45s.py` 冒頭の `SEGS`（区間の表）と、各区間の段取り（`CUR_IN`〜`BOUNCE_T0`、`PAPER_PH`、`EROSION_PH`、`COLLAGE_PH`、`CLIMAX_MODES`）にまとめてあり、映像と音の両方がここを参照します。モチーフは「モチーフ」の節の `motif_*()` 関数、区間ごとの描画は `sc_*()` 関数です。

## 写真の差し替え

`photos/` フォルダに画像（jpg、png、webp）を置くと、ファイル名順に写真断片として使われます（45秒版のみ）。その場合、手続き生成の写真断片は写真断片の枠から外れます。風景、団地、廊下、目などのモチーフは描いたものがそのまま使われます。
