# 読み込み中のあなた — 30秒版

15秒の初稿を30秒に延ばした版です。破壊を5回繰り返しますが、回ごとに違う手法を使います。

| ファイル | 内容 |
| --- | --- |
| `render.py` | 15秒版の生成スクリプト（制作者の原本。無変更。出力先は `/home/claude/` のまま） |
| `render_30s.py` | 30秒版の生成スクリプト。`render.py` の素材（紙、疑似文字、ウィンドウ、マスコット、写真断片、エフェクト、フック、仕上げ）をそのまま使い、30秒のタイムラインと新しい破壊の型を足したもの |
| `loading_you_30s_1080x1920.mp4` | 成果物（1080×1920、30fps、30.0秒、900フレーム、音声付き） |
| `contact_sheet.png` | 主要な時刻のコマを並べたもの |

## 構成

破壊は5回で、回を追うごとに強く長くなります。間に挟む「静」は短く、戻るたびに何かが1つ増えるか、少し間違っています。**同じ手法の繰り返しに頼らないよう、破壊ごとに手法の系統を変えました。**

| 秒 | 区間 | 手法の系統 | 画面 | 音 |
| --- | --- | --- | --- | --- |
| 0.0–0.1 | フック | 15秒版のまま | 反転してマゼンタとシアンに分離、巨大な疑似文字 | ビットクラッシュの轟音 |
| 0.1–2.4 | 静 I | — | 進行バーが98%で止まる。1.9秒に瞬き。2.1秒から予兆 | ハム、進行クリック |
| 2.4–3.6 | 破壊1「裂け」 | **ずらす**（15秒版の裂け目） | 顔が横に裂けてBが覗き、裂け目が画面全体に広がる。写真ブロックが入れ替わりながら侵入、黄緑の帯、エラー。ときどき1コマだけ静へ戻る | 衝撃音、裂けるクラックル、エラー2音 |
| 3.6–4.4 | 静 II | — | 手の写真がアイコンとして残る | ハム |
| 4.4–6.8 | 破壊2「操作」 | **UIで壊す** | カーソルが目を範囲選択して切り取る（顔に四角い穴）。目を画面中に貼り散らかす。窓が20枚湧き、エラーが連鎖して赤い階段になる。目のない本体が飛び出して跳ね回り、軌跡が消えずに残る | クリック、切り取りの擦過音、貼り付けの音、窓の音、エラーの連打、跳ねる音 |
| 6.8–7.6 | 静 III | — | Bが何食わぬ顔で座っている | ハムが55Hzに下がる |
| 7.6–11.6 | 破壊3「暴走」 | **15秒版の暴走** | 拡大縮小、写真、ブロック破損、帯の反転、赤紫のデュオトーン、巨大な疑似文字、エラー。静かなクローズアップ（目、窓の角、フッター、Bの目）へ2コマだけジャンプカットする。9.6秒に3フレームだけB単独 | 15秒版の0.1秒グリッドのスタッターと48Hz。ジャンプカットの瞬間は音も切れる |
| 11.6–12.0 | 静 IV | — | 窓も写真も化けた文字も残ったまま止まる。目が4pxずれる | ハム |
| 12.0–15.0 | 破壊4「紙」 | **紙と印刷** | 画面がCMYの網点になり、版がずれていく → その印刷物がスキャナーで読まれ、紙が滑って伸びる → 紙が斜めに裂け、上半分が剥がれ落ちて、下から暗いBの層が見える | 網点の干渉音 → スキャナーのモーターとステップ音 → 紙の裂ける音と落ちる音 |
| 15.0–16.0 | 静 V | — | 左半分がA、右半分がB | ハムが52Hzに下がる |
| 16.0–20.9 | 破壊5「全壊」 | **新しい型が1つずつ** | スライドパズル（画面がタイルに割れて入れ替わる）→ ラスタースクロール（行ごとに波打ち、色版ごとに位相がずれる）→ 文字化（画面が疑似文字のモザイクに拭い替わる）→ 折り返し（左右がAとB、四方対称、目の壁紙）→ 入れ子（画面の中に画面が無限に続く）→ 巻き戻し（暴走をビデオテープの早戻しで逆再生）→ 溶解（列ごとに垂れ落ち、ピクセルソートの筋）→ 色の巡回（4色に減色してパレットを回す）。18.6秒に3フレームだけB単独 | 型ごとに違う音：木のクリック、ビブラート、タイプライター、左右に跳ねる和音、下がり続ける音、暴走の音の逆再生、落ちるドローン、チップチューンの分散和音 |
| 20.9–21.5 | 全壊の最後 | **並べる** | 画面が3×5のタイルに割れ、タイルごとに違う型が映る。12fpsで入れ替わる | 全部の型の音を重ねる |
| 21.5–22.0 | 崩落 | **解像度** | 解像度が段階的に落ちていき、最後の1点が次の場面のマスコットになる | 音もビット深度とサンプル数が落ちて消える |
| 22.0–23.8 | 無音の間 | — | 白い紙に小さなマスコット1体。23.0秒に一度だけ瞬く | 完全な無音 |
| 23.8–29.9 | 帰還 | — | 冒頭と同じ画面。ただし窓2枚、目が2px右、5文字目が化けたまま。進行バーが溜まり直し、28.6秒に99%。27.3秒にビデオテープの乱れのような余震。29.6秒にBが1フレーム覗く | ハム、進行クリック、テープのうねり |
| 29.9–30.0 | ループ繋ぎ | 15秒版のまま | フックの3フレーム | 冒頭と同じ轟音 |

破壊の音は別の層で作り、映像と同じ判定でマスクしています。静に戻るコマ、B単独のコマ、ジャンプカットでは音も同時に切れます。

## 画質を保つための工夫

破壊しても画質が落ちにくいように、次の3点に気をつけました。

**1. 破壊は「ずらす・並べ替える・折り返す・置き換える」で作る**
新しい型（UI操作、網点、スキャン、破れ、パズル、ラスター、文字化、折り返し、入れ子、溶解、色の巡回）は、どれも最近傍補間のハードエッジな変形です。画素を溶かさないので、1080pに拡大してもドットのまま残ります。JPEG劣化は暴走中の帯状の一部だけに、モザイクは崩落の数フレームだけに使っています。

| | 前の版 | 今回 |
| --- | --- | --- |
| JPEG劣化・モザイクを使ったフレーム | 228 | 52 |
| 劣化をかけた面積の合計（画面何枚分か） | 288 | 17.9 |

**2. 変化を12fpsで保持する**
暴走の乱数は12fps単位で保持し、紙の粒のちらつきも網点の区間では止めています。毎コマ全体が入れ替わると圧縮で潰れやすいためです。

**3. 書き出し設定を見直した**
H.264をCRF 20・presetメディアムから、CRF 18・preset slow・tune animation（平らな色面と輪郭向け）に変えました。元の画と書き出し後の画の輝度PSNRを測ると、破壊区間で1.1〜1.5dB改善しています。

| 区間 | 以前の設定 | 今回の設定 |
| --- | --- | --- |
| 紙（12–15秒） | 33.6 dB | 34.7 dB |
| 暴走（8–10秒） | 39.2 dB | 40.5 dB |
| 全壊（16–18秒） | 36.5 dB | 38.0 dB |

網点の区間はRGBで測ると22〜24dBまで下がりますが、原因は圧縮ではなく、yuv420の色の間引きです（無圧縮のyuv420でも23dB）。細かい色の点は、投稿先の再圧縮でも同じように色がにじみます。

## 光の点滅への配慮

- 全面の写真は1/3秒単位でしか切り替えない
- デュオトーンは周りと明るさを揃えた色を使う
- 全面写真の最中には、明るいジャンプカットや静へのフラッシュバックを挟まない
- 色の巡回では紙の色を固定する

画面全体の平均輝度が大きく（40段階以上）変わる回数は、どの1秒間でも最大2回（明滅1回）です。

| 項目 | 値 |

## 再現手順

Python 3、numpy、Pillow、ffmpeg（libx264とaac入り）、Noto Sans CJKとDejaVu Sansが必要です。

    pip install numpy pillow
    python3 render_30s.py preview 0 1.0 3.0 5.2 6.5 9.0 12.5 14.5 16.5 18.0 20.0 26.0   # コンタクトシート
    python3 render_30s.py video out.mp4                                                 # 音声付きで書き出し（約3分）

パスと画質は環境変数で上書きできます（`FONT_KANA`、`FONT_SYM`、`FFMPEG`、`OUT_DIR`、`CRF`）。乱数は固定しているので、何度回しても同じ結果になります。

構成は `render_30s.py` 冒頭の `SEGS`（区間の表）と、`BLINKS`、`ERRORS`、`QUIET`、`AFTERSHOCK`、破壊2の段取り（`CUR_IN`〜`BOUNCE_T0`）、破壊4の段取り（`PAPER_PH`）、全壊の型の順番（`CLIMAX_MODES`）にまとめてあり、映像と音の両方がここを参照します。区間ごとの描画は `sc_*()` 関数です。

## 写真の差し替え

`photos/` フォルダに画像（jpg、png、webp）を置くと、ファイル名順に写真断片として使われます（30秒版のみ）。低解像度化は自動です。
